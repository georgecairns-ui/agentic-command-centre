# Route: somewhere else

They may already use something else: their own server, a hosting company, Microsoft Azure, Google Cloud, a NAS box in the office.

## What you do

1. Ask where, and what they already have there (an account, a plan, someone who looks after it).
2. Find out from that service's own pages, not from memory, whether it can:
   - run a small Node or Python program all the time (for the full app), or only serve pages;
   - keep it private behind a sign-in that only people they name can pass;
   - keep their data private (never a public folder or bucket).
3. Tell them plainly what you found, with the page you read: "Yes, it can run the whole app privately", "It can only hold the pages, so we'd need X as well", or "It can't keep it private, so I don't recommend it". If it can't keep it private, don't build it there (rule 1).
4. If it can: say what you'll build and what it costs (rule 5), wait for a yes, and build it from a copy, following the same steps as the closest route page here. Then prove it and record it (rule 6).
5. If you're not sure it's safe, say so, and suggest one of the other 4 routes instead.
